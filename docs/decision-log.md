# Decision log

> Every choice that changes what a number means, with the reason and what else was considered. Newest last.

| # | Date | Decision | Why | Alternatives considered |
|---|---|---|---|---|
| D1 | 2026-11-01 | Use the Census Bureau's international trade API as the only data source for trade and duty | Official, free, monthly, back to 2013, and has duty actually charged (calculated duty), not just announced rates | USITC DataWeb (same data, but needs a login and manual exports); news trackers of announced rates (don't show what was paid) |
| D2 | 2026-11-01 | Measure tariffs as **effective rate = calculated duty ÷ imports for consumption** | Captures exemptions, stacking and trade-agreement treatment in one number; comparable across countries and months | Average of announced rates (ignores exemptions); duty ÷ general imports (general imports include goods into bonded warehouses that pay no duty yet) |
| D3 | 2026-11-01 | Run downloads on GitHub Actions with the API key as a repository secret | census.gov isn't reachable from the build machine, and the key must never be in code or logs; the script prints only whether a key is set | Commit downloaded files by hand (not repeatable) |
| D4 | 2026-11-01 | Ask for country names only in queries without a commodity level | Requesting `CTY_NAME` together with `COMM_LVL` returns no data (HTTP 204). Found by testing; names now come from the country-total query | Hard-coded name list (would go stale) |
| D5 | 2026-11-02 | Compare **the same months** of each year (January to the latest month) | Imports are seasonal; a full 2025 against a partial 2026 would be misleading | Rolling 12 months (harder to explain), annual (the latest year is incomplete) |
| D6 | 2026-11-02 | Limit product-level data to 23 "focus" countries plus the all-countries total | Keeps the download to about 70 API calls and 200,000 rows; the focus countries cover the largest suppliers and the main alternatives to China | All 230 countries at product level (over 1 million rows, mostly tiny values) |
| D7 | 2026-11-02 | Fetch HTS 10-digit data for the simulator | Quantities (units, pairs, dozens) exist only at 10 digits; 6-digit totals mix units, so their quantity is reported as zero | Use 6-digit values only (no per-unit figures at all) |
| D8 | 2026-11-02 | Simulator compares **the same $100 of goods**, not average unit prices | Average price = value ÷ units mixes cheap and premium models: a China "video game console" averages $41 against $254 from Vietnam, because they're different products. Comparing $100 of goods isolates what tariffs and freight add | Compare unit prices (misleading); let users type their own price (useful later, but needs a default anyway) |
| D9 | 2026-11-02 | Simulator uses the **latest month's** tariff rate, or the year so far when the latest month has under $2 million of trade | The rules changed on 24 July 2026, so the year-so-far rate would mix old and new tariffs; a tiny month gives an unstable rate | Year-so-far rate always (out of date); fixed headline rates per country (ignore exemptions) |
| D10 | 2026-11-02 | Check the method against CBP's reported IEEPA collections | An independent check: extra duty Feb 2025 – Feb 2026 in product groups mainly hit by IEEPA tariffs = $150B in our data vs about $166B reported by CBP. Chapters mainly under Section 232 (steel, aluminum, copper, vehicles, wood) are counted separately ($67B), since those tariffs weren't struck down | No check (no way to tell if the method is sound) |
| D11 | 2026-11-02 | Don't subtract refunds from calculated duty | Census reports duty as assessed at entry; refunds are reported separately by CBP and not by country or product. The site shows refunds as their own figure | Estimate refunds by country (no data to do it) |
| D12 | 2026-11-02 | Smartphone shares use imports for consumption, not general imports | Consistent with every other number on the site. (The early demo used general imports, which gave India 19% → 58%; the consistent figure is 17% → 49%) | General imports (inconsistent base) |
| D13 | 2026-11-02 | Say that a country's gain is not proof of rerouting, and name the main alternative | Taiwan's growth is mostly computers and servers (+$88B in HS chapter 84), driven by data-center demand, not only by goods leaving China | Present gains as "diversion" without caveat (overclaims) |
| D14 | 2026-11-02 | Refund route rules live in one JavaScript file used by both the page and the tests | One source of truth: the tests check exactly the code the page runs | Rules duplicated in the page and a test script (can drift) |
| D15 | 2026-11-02 | Facts only on policy | Tariffs are politically contested; the project's job is to show what happened and what it cost, with sources, not to judge | Commentary on whether tariffs "worked" |
